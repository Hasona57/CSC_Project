Exercise 1: Temperature Conversion

Task: Write a program that reads a temperature in Celsius from the user (as a decimal number), converts it to Fahrenheit, and displays the calculated result clearly on the screen.

Formula to use: Fahrenheit = (Celsius * 9.0 / 5.0) + 32.0

Click to view Solution & Explanation

Source Code Solution:

#include <iostream>
using namespace std;

int main() 
{
    float celsius, fahrenheit;
    cout << "Enter Temperature in Celsius: ";
    cin >> celsius;
    
    fahrenheit = (celsius * 9.0 / 5.0) + 32.0;
    cout << "Your Temperature in Fahrenheit = " << fahrenheit << " F" << endl;
    
    return 0;
}

Explanation:

  • float variables: We use float instead of int so our program can work with numbers that have decimal points (like 24.5 degrees).
  • Basic Math: The program multiplies the input by 9.0, divides it by 5.0, and adds 32 to get the correct Fahrenheit value.

Exercise 2: Rectangle Dimensions

Task: Write a program that prompts the user to input the length and width of a rectangle as floating-point values. The program must calculate and output its total area and perimeter.

Click to view Solution & Explanation

Source Code Solution:

#include <iostream>
using namespace std;

int main() 
{
    double length, width;
    cout << "Enter the length: ";
    cin >> length;
    cout << "Enter the width: ";
    cin >> width;
    
    cout << "Area      = " << length * width << endl;
    cout << "Perimeter = " << 2 * (length + width) << endl;
    
    return 0;
}

Explanation:

  • Data Types: length and width are declared as double so that the user can safely type in decimal configurations (like 5.5) without losing precision.
  • Interactive Streams: cin takes user values from the terminal screen and passes them into our declared storage variables dynamically.

Exercise 3: Distance and Slope Between Two Points

Task: Write a program that asks the user to type in the grid coordinates for two separate points: (x1, y1) and (x2, y2). The program should then calculate and show two things: the straight-line distance between those points, and the slope of the line connecting them.

Click to view Solution & Explanation

Source Code Solution:

#include <iostream>
#include <cmath> // Required for sqrt and pow
using namespace std;

int main() 
{
    double x1, y1, x2, y2;
    cout << "Enter x1 y1: ";
    cin >> x1 >> y1;
    cout << "Enter x2 y2: ";
    cin >> x2 >> y2;
    
    double distance = sqrt(pow(x2 - x1, 2) + pow(y2 - y1, 2));
    double slope = (y2 - y1) / (x2 - x1);
    
    cout << "Distance = " << distance << endl;
    cout << "Slope    = " << slope << endl;
    
    return 0;
}

Explanation:

  • cmath Library: Including <cmath> is essential here because it lets us use built-in math tools like pow() to square numbers and sqrt() to find square roots.
  • Parentheses Order: Putting brackets around (y2 - y1) and (x2 - x1) tells the computer to finish the subtraction blocks first before dividing them.
