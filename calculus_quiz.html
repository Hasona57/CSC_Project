Lecture 1

Flashcards

1. Definition of a Function, Domain, and Range

Function (y = f(x)): A relation between x and y where each input value of x has a unique (single) output value of y (e.g., y = x2 is a function, while y2 = x is not).
Domain D(f): The set of all possible input values of x (read from left to right on the horizontal axis).
Range R(f): The set of all output values of y (read from bottom to top on the vertical axis).

2. Domain Rules for Algebraic Functions

Even Root (y = √g(x)): Inside of the root must be non-negative: g(x) ≥ 0.
Rational / Fraction (y = 1 / g(x)): Denominator cannot be zero: g(x) ≠ 0.
Even Root in Denominator (y = 1 / √g(x)): Inside of the root must be strictly positive: g(x) > 0.
Natural Logarithm (y = ln(g(x))): Inside of the logarithm must be strictly positive: g(x) > 0.

3. Symmetry: Even and Odd Functions

Replace every x with -x in f(x) to test symmetry:
Even Function: f(-x) = f(x) for all x in the domain. Symmetric about the y-axis (e.g., y = x2, y = |x|, y = sec(x)).
Odd Function: f(-x) = -f(x) for all x in the domain. Symmetric about the origin (e.g., y = x3, y = x, y = csc(x)).
Neither: f(-x) ≠ f(x) and f(-x) ≠ -f(x) (e.g., f(x) = x3 + 4x2).

4. Common Parent Functions (Domains & Ranges)

y = x2, y = x4, y = |x|: D(f) = ℜ, R(f) = [0, ∞)
y = x3, y = ∛x: D(f) = ℜ, R(f) = ℜ
y = √x, y = ∜x: D(f) = [0, ∞), R(f) = [0, ∞)
y = 1 / x: D(f) = ℜ - {0}, R(f) = ℜ - {0}
y = 1 / x2: D(f) = ℜ - {0}, R(f) = (0, ∞)
y = √(a2 - x2) (Upper Semicircle): D(f) = [-a, a], R(f) = [0, a]

5. Vertical and Horizontal Graph Shifts

Vertical Shift (y = f(x) + k): Shifts the graph up k units if k > 0, and down |k| units if k < 0.
Horizontal Shift (y = f(x + h)): Shifts the graph left h units if h > 0, and right |h| units if h < 0.

6. Reflections and Absolute Value of a Function

X-Axis Reflection (y = -f(x)): Reflects the entire graph of f(x) across the x-axis.
Y-Axis Reflection (y = f(-x)): Reflects the entire graph of f(x) across the y-axis.
Absolute Value (y = |f(x)|): Keeps positive y-values unchanged and reflects only the negative part of the graph (below the x-axis) upward across the x-axis.

7. Reciprocal Function Transformation (y = 1 / f(x))

Sign: 1 / f(x) has the exact same sign (+ve or -ve) as f(x).
Behavior: Where f(x) is large, 1 / f(x) is small; where f(x) is small, 1 / f(x) is large.
Asymptotes & Limits: As f(x) → ±∞, 1 / f(x) → 0. Where f(x) → 0, 1 / f(x) → ±∞ (vertical asymptote).
