Lecture 1

Flashcards

1. Definition of a Function, Domain, and Range

Function (y = f(x)): A relation between x and y where each input value of x has a unique (single) output value of y (e.g., y = x2 is a function, while y2 = x is not).
Domain D(f): The set of all possible input values of x (read from left to right on the horizontal axis).
Range R(f): The set of all output values of y (read from bottom to top on the vertical axis).

2. Domain Rules for Algebraic Functions

Even Root (y = √f(x)): The function under the root must not be negative so it must be larger than or equal to 0: f(x) ≥ 0.
Rational / Fraction (y = 1 / g(x)): Denominator part must not be zero;: g(x) ≠ 0.
Even Root in Denominator (y = 1 / √g(x)): So if we have a function under the root in the denominator, it must be larger than 0 and cannot be eqaul: g(x) > 0.
Natural Logarithm (y = ln(g(x))): Logarithm domain is from always positive: g(x) > 0.

Lecture 2

Flashcards

1. Inverse, Exponential, and Logarithmic Functions

One-to-One & Horizontal Line Test: A function has an inverse if and only if it is one-to-one (every horizontal line intersects its graph at most once).
Finding the Inverse f-1(x): (1) Check that f(x) is one-to-one, (2) replace f(x) with y, (3) solve for x in terms of y, and (4) swap x and y. The graph of f-1(x) is a reflection of f(x) across the line y = x.
Domain, Range & Cancellation: D(f-1) = R(f) and R(f-1) = D(f). Also, f(f-1(x)) = x and f-1(f(x)) = x.
Exponential Function (y = ax, y = ex): Always positive with D(f) = ℜ and R(f) = (0, ∞), passing through (0, 1).
Natural Logarithm (y = ln(x)): Inverse of ex with D(f) = (0, ∞) and R(f) = ℜ. Key rules: ln(xy) = ln(x) + ln(y), ln(x / y) = ln(x) - ln(y), and ln(xr) = r ln(x).

2. Derivatives of Exponential and Logarithmic Functions

Basic, Product & Quotient Rules: (xn)' = nxn-1, (f · g)' = f'g + fg', and (f / g)' = (f'g - fg') / g2.
Trigonometric Derivatives: (sin x)' = cos x, (cos x)' = -sin x, (tan x)' = sec2x, (cot x)' = -csc2x, (sec x)' = sec x tan x, (csc x)' = -csc x cot x.
Exponential & Log Derivatives: (ex)' = ex, (ax)' = ax ln(a), (ln x)' = 1 / x, and (logax)' = 1 / (x ln(a)).
Chain Rule: d/dx [f(g(x))] = f'(g(x)) · g'(x) (derivative of outside times derivative of.
Implicit & Logarithmic Differentiation: For implicit equations, differentiate both sides with respect to x and multiply y-derivatives by y'. For complex products/quotients or variable powers, try to take ln both sides.

Lecture 3

Flashcards

1. Inverse Trigonometric Functions (Domains, Ranges & Identities)

sin-1(x) & cos-1(x): Both have Domain [-1, 1]. Range of sin-1(x) is [-π/2, π/2] (odd), while Range of cos-1(x) is [0, π].
tan-1(x) & cot-1(x): Both have Domain (-∞, ∞). Range of tan-1(x) is (-π/2, π/2) (odd), while Range of cot-1(x) is (0, π).
sec-1(x) & csc-1(x): Both have Domain (-∞, -1] ∪ [1, ∞). Range of sec-1(x) is [0, π/2) ∪ (π/2, π], and Range of csc-1(x) is [-π/2, 0) ∪ (0, π/2] (odd).
Key Identities: sin-1(x) + cos-1(x) = π/2, tan-1(x) + cot-1(x) = π/2, sec-1(x) + csc-1(x) = π/2, sec-1(x) = cos-1(1/x), and csc-1(x) = sin-1(1/x).

2. Derivatives of Inverse Trigonometric Functions (with Chain Rule)

d/dx [sin-1(u)]: u' / √(1 - u2)
d/dx [cos-1(u)]: -u' / √(1 - u2)
d/dx [tan-1(u)]: u' / (1 + u2)
d/dx [cot-1(u)]: -u' / (1 + u2)
d/dx [sec-1(u)]: u' / (|u|√(u2 - 1))
d/dx [csc-1(u)]: -u' / (|u|√(u2 - 1))

Lecture 4

Flashcards

1. Hyperbolic Functions (Definitions, Domains, Ranges & Identities)

Definitions: sinh(x) = (ex - e-x) / 2 [D = ℜ, R = ℜ, odd], cosh(x) = (ex + e-x) / 2 [D = ℜ, R = [1, ∞), even], and tanh(x) = sinh(x) / cosh(x) = (ex - e-x) / (ex + e-x) [D = ℜ, R = (-1, 1), odd].
Reciprocals: sech(x) = 1 / cosh(x) [D = ℜ, R = (0, 1], even], csch(x) = 1 / sinh(x) [D = ℜ - {0}, R = ℜ - {0}, odd], and coth(x) = cosh(x) / sinh(x) [D = ℜ - {0}, R = ℜ - [-1, 1], odd].
Fundamental Identities: cosh(x) + sinh(x) = ex, cosh(x) - sinh(x) = e-x, cosh2(x) - sinh2(x) = 1, 1 - tanh2(x) = sech2(x), and coth2(x) - 1 = csch2(x).
Double-Angle Identities: sinh(2x) = 2 sinh(x) cosh(x) and cosh(2x) = cosh2(x) + sinh2(x).

2. Inverse Hyperbolic Functions & Derivatives

Hyperbolic Derivatives: (sinh u)' = cosh(u) u', (cosh u)' = sinh(u) u', (tanh u)' = sech2(u) u', (coth u)' = -csch2(u) u', (sech u)' = -sech(u) tanh(u) u', and (csch u)' = -csch(u) coth(u) u'.
Logarithmic Forms: sinh-1(x) = ln(x + √(x2 + 1)) for all x, cosh-1(x) = ln(x + √(x2 - 1)) for x ≥ 1, and tanh-1(x) = 0.5 ln((1 + x) / (1 - x)) for |x| < 1.
Inverse Hyperbolic Derivatives: (sinh-1x)' = 1 / √(1 + x2), (cosh-1x)' = 1 / √(x2 - 1), (tanh-1x)' = 1 / (1 - x2) [|x| < 1], (coth-1x)' = 1 / (1 - x2) [|x| > 1], (sech-1x)' = -1 / (x√(1 - x2)), and (csch-1x)' = -1 / (|x|√(1 + x2)).

Lecture 5

Flashcards

1. L'Hôpital's Rule for Quotient Indeterminate Forms (0/0 and ∞/∞)

L'Hôpital's Rule: If limx→a [f(x) / g(x)] produces the indeterminate form 0 / 0 or ∞ / ∞, then limx→a [f(x) / g(x)] = limx→a [f'(x) / g'(x)] (differentiate numerator and denominator separately).
Repeated Application: You can apply L'Hôpital's Rule multiple times in succession as long as the limit remains in the form 0 / 0 or ∞ / ∞.
Essential Limits to Remember: e∞ = ∞, e-∞ = 0, ln(0+) = -∞, and ln(∞) = ∞.

2. Indeterminate Products, Differences, and Powers

Indeterminate Products (0 · ∞): Rewrite f(x) · g(x) as a fraction f(x) / (1 / g(x)) or g(x) / (1 / f(x)) to convert it into 0 / 0 or ∞ / ∞ before applying L'Hôpital's Rule.
Indeterminate Differences (∞ - ∞): Combine the terms into a single fraction using a common denominator to convert into 0 / 0 or ∞ / ∞.
Indeterminate Powers (1∞, 00, ∞0): For y = [f(x)]g(x), (1) take the natural log: ln(y) = g(x) ln(f(x)) = ln(f(x)) / (1 / g(x)), (2) find L = lim ln(y) using L'Hôpital's Rule, and (3) take the exponential: Final Limit = eL.

Lecture 6

Flashcards

1. Taylor and Maclaurin Series

Taylor Series (at x = c): f(x) = Σ [f(n)(c) / n!](x - c)n = f(c) + f'(c)(x - c) + [f''(c) / 2!](x - c)2 + [f'''(c) / 3!](x - c)3 + ...
Maclaurin Series (at c = 0): f(x) = Σ [f(n)(0) / n!]xn = f(0) + f'(0)x + [f''(0) / 2!]x2 + [f'''(0) / 3!]x3 + ...
Standard Maclaurin Series:
• ex = 1 + x + x2/2! + x3/3! + ...
• sin(x) = x - x3/3! + x5/5! - ... and sinh(x) = x + x3/3! + x5/5! + ...
• cos(x) = 1 - x2/2! + x4/4! - ... and cosh(x) = 1 + x2/2! + x4/4! + ...
• 1 / (1 - x) = 1 + x + x2 + x3 + ... and ln(1 - x) = -x - x2/2 - x3/3 - ...

2. Analytic Geometry: The Circle

Center-Radius Form: The equation of a circle with center (h, k) and radius r is (x - h)2 + (y - k)2 = r2. (If r2 = 0, it is a single point (h, k); if r2 < 0, there is no graph).
Completing the Square: Convert x2 ± ax + b into (x ± a/2)2 - (a/2)2 + b to find the center and radius from general form.
Tangent & Normal Lines to a Circle: Differentiate implicitly: 2(x - h) + 2(y - k)y' = 0 ⇒ slope of tangent m = y' = (h - x) / (y - k). The slope of the normal line is -1 / m.
